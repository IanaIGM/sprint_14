# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

main.go - инициализирует базу данных и запускает сервер для работы приложения.

Директория utils - содержит пакет с кодом реализующим расчёт следующей даты выполнения задачи на основе правил повторения.

Директория server - хранит код для запуска сервера.

Директория db - содержит пакеты, которые обеспечивают работу с базой данных.

Директория api содержит пакеты с кодом, реализующим совершение операций с задачами.
